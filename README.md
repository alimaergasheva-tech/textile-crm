# SaaS CRM для текстильных фабрик

Аналог Битрикс24 под текстильное производство готовой продукции: CRM, каталог с BOM, склад, производство и бригады, обратная связь и рекламации, Telegram Mini App. Продаётся как SaaS (много фабрик-клиентов).

## Принятые решения (23.11.2026)
- Продукт: SaaS, мультитенантность (изоляция данных фабрик), панель владельца платформы, тарифы
- Производство: смешанное (свои цеха и подрядчики)
- Масштаб: более 100 пользователей на фабрику
- Мини-приложение: Telegram Mini App
- MVP: CRM; каталог, BOM, склад; производство и бригады; обратная связь и рекламации
- Валюты: сум и USD. Языки: русский и узбекский
- Интеграция с 1С: позже (закладываем внешние ID и API)

## Порядок работы
Работаем этапами из docs/Tasks.md. После каждого этапа рабочая демо-версия и подтверждение, затем следующий этап. Этап 1 «Фундамент» закрыт и проверен запуском. Этап 2 «CRM» (клиенты, лиды, сделки-канбан, задачи) написан. Этап 3 «Каталог» (модели, варианты, BOM, маршрут, прайсы, КП) написан. Этап 9 «Пилот и SaaS» подготовлен в коде (панель платформы /platform, лимиты тарифа, блокировка, вход поддержки с журналом, создание фабрики, экспорт и внешние ID, скрипт нагрузки, документы по эксплуатации, обучению и пилоту) и ждёт проверки; сам пилот, серверы, бэкапы и Sentry — работа вне кода. Этап 8 «Обратная связь и рекламации» (автозапрос оценки через сутки после отгрузки, публичная страница /rate/<токен>, рекламации с решением «замена / возврат / скидка», эскалация через 48 ч, предложения в том числе анонимные, статистика) написан, ждёт проверки; фото к рекламациям и экраны Mini App для клиента не сделаны. Этап 7 «Telegram Mini App» (бригадир, ОТК, зарплата, офлайн-очередь с Idempotency-Key, вход по подписи Telegram) написан, ждёт проверки. Этап 6 «Отгрузка» (частичные отгрузки, накладная и упаковочный лист, лимит, оплачено) написан, ждёт проверки. Этап 5 «Заказы и производство» (заказ из сделки, кредитный лимит, авторезерв, задания на разницу, этапы, списание по BOM, ОТК) написан, ждёт проверки. Этап 4 «Склад» (остатки из движений, партии и рулоны ткани, резервы, инвентаризация, сверка) написан, ждёт проверки; не сделаны ночная сверка по расписанию и печать этикеток. Языки ru/uz/en/tr, живой фон и шрифты добавлены.

## Запуск (этап 1)
Нужны Node 20+, pnpm и Docker.
```
cp .env.example .env
pnpm install
pnpm infra:up          # Postgres, Redis, MinIO
set -a; source .env; set +a
pnpm db:migrate        # применить миграции
pnpm test:rls          # проверка изоляции фабрик (5 тестов)
```

### API и демо-данные
```
pnpm db:migrate && pnpm --filter @textile/api db:seed   # 2 демо-фабрики
pnpm --filter @textile/api dev                          # http://localhost:3000
curl -X POST localhost:3000/auth/login -H 'content-type: application/json' \
  -d '{"tenant":"demo-a","email":"owner@demo-a.uz","password":"demo12345"}'
```
Демо-пароли только для разработки. Конечные точки этапа 1: `/auth/*`, `/users`, `/roles`, `/permissions`, `/reference-values`, `/audit`, `/files`.

## Mini App (этап 7)
- Проверка в браузере: http://localhost:5174/?t=demo-a, вход по почте и паролю (вне Telegram).
- В Telegram: создайте бота в @BotFather, впишите `TELEGRAM_BOT_TOKEN` и `TELEGRAM_BOT_USERNAME` в `.env`, дайте Mini App публичный https-адрес (например, `cloudflared tunnel --url http://localhost:5174`) и укажите его в BotFather как Web App.
- Привязка сотрудника: «Бригады» → состав → кнопка «Telegram» даёт ссылку-приглашение (действует 7 дней).
