# Инструкции для сотрудников пилотной фабрики / Pilot fabrikasi xodimlari uchun yo‘riqnoma

## RU
**Менеджер по продажам.** Лид → «В клиента» → сделка → КП из каталога → «Выиграна» → «Заказ из выигранной сделки». Подтвердите заказ: система сама зарезервирует готовый товар и создаст задания на производство для остального. Проверьте кредитный лимит клиента: при превышении заказ уходит на подтверждение руководителю.

**Бригадир (Telegram Mini App).** Откройте бота, нажмите кнопку приложения. Первый вход — по личной ссылке-приглашению от администратора (действует 7 дней). Во вкладке «Задания» нажмите «Сделано N». Без интернета отметки сохраняются на телефоне и отправятся сами; повторно считаться не будут.

**Контролёр ОТК.** Во вкладке ОТК укажите годные и брак с причиной. Годные автоматически попадают на склад готовой продукции и резервируются под заказ.

**Кладовщик.** Приход, расход, перемещение — только через раздел «Склад» (остатки считаются из движений, правка остатка вручную невозможна). Инвентаризация: «Начать», ввести посчитанное, «Закрыть».

**Отгрузка.** Заказ → «Отгрузка» → накладная и упаковочный лист (PDF) → «Отгрузить». Через сутки клиент получит просьбу оценить заказ.

**Рекламации.** «Обратная связь» → «Рекламации»: регистрация, «В работу», решение (замена / возврат / скидка). Срок — 48 часов, затем руководитель получит эскалацию.

**Анонимное предложение.** «Обратная связь» → «Предложения», флажок «Анонимно»: автор не сохраняется.

## UZ
**Sotuv menejeri.** Lid → «Mijozga aylantirish» → bitim → katalogdan tijoriy taklif → «Yutilgan» → «Yutilgan bitimdan buyurtma». Buyurtmani tasdiqlang: tizim tayyor tovarni o‘zi rezerv qiladi, qolganiga ishlab chiqarish topshiriqlarini yaratadi. Kredit limitidan oshsa, buyurtma rahbar tasdig‘iga yuboriladi.

**Brigadir (Telegram Mini App).** Botni oching, ilova tugmasini bosing. Birinchi kirish — administrator bergan shaxsiy havola orqali (7 kun amal qiladi). «Topshiriqlar» bo‘limida «Bajarildi N» tugmasini bosing. Internet bo‘lmasa, belgilar telefonda saqlanadi va o‘zi yuboriladi; ikki marta hisoblanmaydi.

**TKK nazoratchisi.** TKK bo‘limida yaroqli va brak sonini sabab bilan kiriting. Yaroqlilari tayyor mahsulot omboriga tushadi va buyurtmaga rezerv qilinadi.

**Omborchi.** Kirim, chiqim, ko‘chirish — faqat «Ombor» bo‘limida (qoldiq harakatlardan hisoblanadi, qo‘lda o‘zgartirib bo‘lmaydi). Inventarizatsiya: «Boshlash», sanalganini kiriting, «Yopish».

**Jo‘natish.** Buyurtma → «Jo‘natish» → yuk xati va qadoqlash varaqasi (PDF) → «Jo‘natish». Bir kundan so‘ng mijozga baholash so‘rovi boradi.

**Reklamatsiyalar.** «Fikr-mulohaza» → «Reklamatsiyalar»: ro‘yxatga olish, «Ishga olish», yechim (almashtirish / qaytarish / chegirma). Muddat — 48 soat, so‘ng rahbarga eskalatsiya boradi.

**Anonim taklif.** «Fikr-mulohaza» → «Takliflar», «Anonim» belgisi: muallif saqlanmaydi.
