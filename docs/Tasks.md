# Tasks.md: план разработки SaaS CRM для текстильных фабрик

Версия от 23.11.2026

## Правила и этапы

Работа идёт этапами. Каждый этап заканчивается работающей демо-версией и подтверждением владельца проекта, без него следующий не начинается. Номера в скобках — требования из PRD. Задачу можно отметить готовой, только если выполнен критерий готовности этапа.

| Этап | Что получаем | Нужно до него |
| --- | --- | --- |
| 1. Фундамент | Проект, БД, вход, роли, фабрики, макет | — |
| 2. CRM | Лиды, клиенты, сделки, канбан, задачи | 1 |
| 3. Каталог | Модели, варианты, BOM, маршруты, цены, КП | 1 (для КП ещё 2) |
| 4. Склад | Движения, остатки, резервы | 3 |
| 5. Заказы и производство | Заказ, задания, этапы, бригады, брак, подрядчики | 2, 4 |
| 6. Отгрузка | Отгрузки, документы, кредитный лимит | 5 |
| 7. Mini App | Бригадир, ОТК, склад, менеджер, клиент, уведомления | 5, 6 |
| 8. Обратная связь | Оценки, рекламации, предложения, статистика | 6, 7 |
| 9. Пилот и SaaS | Тарифы, панель владельца, нагрузочные тесты, первая фабрика | 1–8 |

Размер задачи: S — до полудня, M — до 2 дней, L — до недели; больше дробится.

## Этап 1. Фундамент

Готово, когда: руководитель фабрики входит в систему, создаёт пользователя и роль; данные двух фабрик не перемешиваются.

- [ ] 1.1 Монорепо: `apps/web`, `apps/miniapp`, `apps/api`, `packages/ui`, `packages/shared`; линтер, типы, CI (S)
- [ ] 1.2 Docker Compose: PostgreSQL, Redis, MinIO; команда «одной командой поднять всё» (S)
- [ ] 1.3 Миграции БД: tenants, users, roles, permissions, audit_log, reference_values, files (M)
- [ ] 1.4 Row Level Security + автотест «фабрика A не видит B» (M) (SAAS-1)
- [ ] 1.5 Вход: логин, JWT + refresh, восстановление пароля (M)
- [ ] 1.6 RBAC: права на эндпоинтах, «только свои записи», тесты прав (M)
- [ ] 1.7 Журнал действий на всех изменяющих операциях (S)
- [ ] 1.8 Файлы: предподписанная загрузка в S3, привязка к сущности (S)
- [ ] 1.9 Веб-каркас: меню модулей, поиск, темы, RU/UZ, две валюты (M)
- [ ] 1.10 Настройки: пользователи, роли, справочники, курсы валют (M)
- [ ] 1.11 Seed-данные: 2 демо-фабрики (S)
